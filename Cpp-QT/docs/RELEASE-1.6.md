# 拾词 MyDict Qt 1.6

## 新增与改进

- 今日词汇：从新闻、科学、社会报道中选词，提供来源链接、配图、逐句中英文摘要、语法配色、例句和词形派生；查阅后自动收藏，支持历史回看。
- 收藏复习：释义选择与选词填空两种模式；答错或选择“不太熟”增加权重 30%，答对减少 30%。填空答题后显示四个选项的释义及例句翻译，切换到查词页后可以继续复习。
- 单词本按复习权重从高到低排列，增加页内编号与页码跳转；只显示收藏词，取消收藏后释义仍保留在缓存。
- 优化窄窗口选项布局、词性按钮、字体加载及今日词汇排版；释义区域不再使用交替背景或分隔线。
- 保留 C# 与 Windows、macOS、Linux Qt 的共享 SQLite 词库协议，新增今日词汇缓存和同步支持。

## 下载与运行

- Windows x64：解压后运行 `bin/MyDictQt.exe`。
- Linux x64：解压后运行顶层 `MyDictQt` 启动脚本。
- macOS：按处理器选择 arm64 或 x64 包，解压后运行 `.app`；应用尚未经过 Apple 公证。

压缩包包含 Qt 运行库，无需安装 Conda；附带 SHA256 校验文件。程序内部版本号为 `1.6.0-shared`，Git 标签为 `qt-v1.6`。

## 升级

先关闭旧版并备份用户数据，再将新版程序解压到独立目录。保留自己的 `settings.json`、字体及 SQLite 词库；不要用示例配置覆盖个人设置。DeepSeek 和同步凭证由用户自行配置，发布包不包含私人词库或密钥。C# 固定版标签不变。
